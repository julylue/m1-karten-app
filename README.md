# M1 Karten

Karteikarten-App für M1 Psychologie (FernUni Hagen). Statische Seite, veröffentlicht über Netlify.

- `index.html`: die App (Abfrage mit FSRS, Durchlauf zum Anhören, Kartenübersicht)
- `sw.js`: Offline-Speicher
- Karten und Lernstand liegen in der Google-Tabelle "M1 Karten", angebunden über ein Google-Skript.
